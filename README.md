# PSYCHE Academic Care

Official modern web application and management platform for **PSYCHE Academic Care** — empowering students with quality coaching, expert faculty mentors, routine scheduling, and full academic management.

## 🚀 Key Features

- **Public Educational Portal:**
  - Dynamic course programs (Class 8-12, SSC/HSC, Medical & Engineering Admission)
  - Interactive Teacher & Faculty showcase
  - Board & Admission results records
  - Online student admission application flow
  - Bilingual support (Bangla & English)

- **Student Portal:**
  - View class routines and weekly schedules
  - Real-time notice board announcements
  - Academic result lookup and report cards
  - Fee invoice tracking

- **Admin Management Portal:**
  - **Faculty Management:** Add, manage, and remove faculty members with profile photo uploads and image URLs.
  - **Notice Board Publishing:** Post urgent and general notices displayed instantly to students.
  - **Class Routine Management:** Create and organize class schedules by batch, day, and room.
  - **Admissions & Results:** Review student applications and publish exam scorecards.
  - **Invoicing & Fees:** Track payments, collection metrics, and dues.

---

## 🛠️ Tech Stack

- **Framework:** React + TypeScript + Vite
- **Styling:** Tailwind CSS + Lucide Icons
- **State & Storage:** Context API + LocalStorage persistence
- **Internationalization:** Custom Bangla & English i18n

## 💻 Run Locally

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or bun

### Setup & Launch

1. Clone repository:
   ```bash
   git clone https://github.com/sharjil02/-PSYCHE-Academic-Care.git
   cd -PSYCHE-Academic-Care
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
